## Description

CLI tool that parses shell history to detect typos and suggest corrected commands using a rule-based engine.

## Résumé

Shell AutoFix est un outil CLI Python autonome, sans dépendance externe, conçu pour analyser l'historique du terminal (bash ou zsh) afin de détecter les fautes de frappe dans les commandes via la distance de Levenshtein. Il propose automatiquement des corrections pour plus de 50 outils CLI courants et gère efficacement les cas limites comme les fichiers vides ou les caractères non ASCII. Avec 0 étoile et un nombre limité de fonctionnalités de base, la recommandation est **faible**, le projet semblant être un exercice d'apprentissage ou un prototype plus qu'un outil mature prêt pour la production.
