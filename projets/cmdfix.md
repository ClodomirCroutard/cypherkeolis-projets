## Description

CLI tool that suggests corrected shell commands using regex heuristics with the Python standard library

## Résumé

**cmdfix** est un utilitaire CLI en Python, conçu sans dépendances externes, qui détecte et corrige les erreurs de frappe courantes ainsi que les problèmes de permissions dans les commandes shell. Il propose des corrections basées sur des heuristiques régulières (regex) et s'adapte facilement à de nouveaux modèles d'erreurs.
