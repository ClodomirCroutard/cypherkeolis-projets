## Description

Real-time log analyzer and anomaly detector using Python standard library for error spikes and latency regressions.

## Résumé

**log-pulse** est un outil léger en Python, basé uniquement sur la bibliothèque standard, conçu pour l'analyse en temps réel des fichiers de journaux afin de détecter les pics d'erreurs et les régressions de latence. Ses fonctionnalités principales incluent le suivi efficace des logs via une fenêtre glissante, l'analyse par expressions régulières et la génération de rapports JSON structurant l'état de santé du système. Compte tenu de son score d'étoiles nul, de sa nature expérimentale (topic "research") et de la disponibilité d'alternatives plus établies, le niveau de recommandation est **faible**.
