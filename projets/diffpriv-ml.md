## Description

Differentially private machine learning utilities: DP-SGD, calibrated noise mechanisms, privacy budget accounting.

## Résumé

Ce projet propose une bibliothèque Python légère et auditable pour implémenter la confidentialité différentielle dans le machine learning, avec un accent particulier sur la clarté mathématique des garanties de privacy. Il offre des fonctionnalités essentielles telles que le DP-SGD, des mécanismes de bruit calibrés (Laplace et Gaussien) et le suivi du budget de confidentialité.

Niveau de recommandation : **faible** (en raison de l'absence totale d'étoiles et d'adoption communautaire, bien que le code soit utile comme référence académique).
