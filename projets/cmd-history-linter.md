## Description

CLI tool that parses shell history to detect common mistakes like typos and redundant flags using standard library heuristics.

## Résumé

`cmd-history-linter` est un outil CLI Python léger qui analyse l'historique du terminal pour détecter les erreurs courantes, les fautes de frappe et les incohérences de syntaxe grâce à des heuristiques simples. Ses fonctionnalités principales incluent l'absence totale de dépendances externes, la prise en charge croisée de Bash et Zsh, et la génération de rapports de console clairs sur les commandes problématiques. Je recommande ce projet à un niveau **faible**, car sa nature de script unique et son faible nombre d'étoiles suggèrent qu'il s'agit d'un utilitaire de niche ou d'un projet de recherche non mature.
