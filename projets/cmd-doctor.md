## Description

CLI tool suggesting intended commands via Levenshtein distance and installed executables, without executing anything.

## Résumé

**cmd-doctor** est un outil CLI en Python conçu pour auditer de manière statique et sécurisée l'historique des commandes shell afin d'identifier les fautes de frappe et les drapeaux redondants sans exécuter les instructions. Ses fonctionnalités principales incluent la détection de coquilles via le flou de Levenshtein, l'analyse robuste des fichiers d'historique et la génération de rapports lisibles contenant des suggestions de correction. La recommandation est **faible**, le projet n'ayant actuellement aucune étoile et semblant être une expérimentation ou un projet de recherche de niche.
