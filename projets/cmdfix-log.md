## Description

Python CLI tool logging failed shell commands to JSON and suggesting fixes via a built-in rule engine with custom config support.

## Résumé

**cmdfix-log** est un outil CLI Python, sans dépendances externes, conçu pour journaliser les commandes shell échouées dans un fichier JSON local et proposer des correctifs via un moteur de règles intégré. Il se distingue par sa simplicité d'installation (script unique), sa capacité à étendre les correctifs via une configuration personnalisée et une exécution sécurisée des processus.

**Niveau de recommandation : Faible** (projet très récent avec 0 étoile, potentiellement un projet d'apprentissage ou de recherche plutôt qu'un outil de production éprouvé).
