## Description

CLI tool that analyzes shell history to detect redundant commands and suggest optimized aliases using standard library statistics.

## Résumé

Ce projet est un outil CLI en Python, sans dépendances externes, conçu pour analyser l'historique du terminal afin d'identifier les commandes répétitives et les séquences redondantes. Il propose automatiquement des alias optimisés et des commandes chaînées pour simplifier le flux de travail, en s'appuyant uniquement sur la bibliothèque standard pour le traitement des données.

**Niveau de recommandation : Faible** (bien que l'outil soit léger et autonome, l'absence d'étoiles et le caractère niche de l'optimisation manuelle limitent son attractivité actuelle).
