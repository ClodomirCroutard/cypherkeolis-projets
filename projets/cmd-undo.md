## Description

Lightweight CLI history manager logging shell commands to JSON with undo and search features using only the Python standard library.

## Résumé

`cmd-undo` est un outil CLI Python léger et hors ligne, conçu pour journaliser les cinq dernières commandes du shell dans un fichier JSON afin de permettre une annulation ou une réexécution simple. Ses fonctionnalités principales incluent la sauvegarde locale des métadonnées (horodatage, code de sortie), la consultation de l'historique et la récupération exacte des chaînes de commande pour copie-coller. Je lui attribue un niveau de recommandation **faible**, car il s'agit d'une réimplémentation redondante des fonctionnalités natives de la plupart des shells (comme `fc` ou `history`) avec une capacité de stockage très limitée.
